# Licensing and attribution status

`LicenseRef-MacAni` is a project-local package metadata marker, not a public license grant. The repository does not currently document licenses or provenance for all pre-existing anime artwork, sound assets, or the user-provided `MacAni-Linux_logo.png`. Do not infer redistribution permission from inclusion in a build or package. Obtain and record the relevant rights and attributions before publishing or redistributing the ISO/packages. Replace this marker with explicit upstream SPDX identifiers and attribution files when confirmed.

The shell/configuration changes are project-specific contributions, but this repository has no top-level license file establishing their reuse terms. The project owner should choose and document a formal source-code license before public release.

The curated upstream packages `macani-liquid-plasma` (GPL-3) and `macani-gtk-theme` (MIT) include their corresponding upstream license texts and provenance notes. They do not resolve licensing for MacAni's pre-existing anime art, audio, or user-supplied logo. Upstream components whose licenses or embedded-media rights were absent or unclear were not redistributed; see [`docs/upstream-review.md`](../docs/upstream-review.md).
